# Simple Python Calculator

A beginner-friendly command-line calculator built in Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Parentheses
- Negative numbers
- Decimal numbers

## How to Run

Run the calculator with:

```bash
python3 calculator.py
```

You can then type expressions like:

```text
2 + 3
7 - 4
6 * 7
(2 + 3) * 4
-5 + 3
```

## Run Tests

To verify the calculator behavior, run:

```bash
python3 -m unittest -v
```

## Files

- calculator.py - the calculator implementation
- test_calculator.py - test cases for the calculator
